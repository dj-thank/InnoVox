# Security

This project is pre-release. No hosted-service security or production-readiness
claim is made by publishing this repository.

Do not post credentials, real conversations, recordings, private project data,
or exploit details containing sensitive user information in public issues.

Use GitHub's private vulnerability reporting feature if it is available for this
repository. If it is unavailable, open a minimal public issue asking the maintainer
for a private contact route, without sensitive details.

The implementation must keep source content separate from trusted instructions,
scope access by user/project/source, bind answers to their consultations, and
keep provider credentials server-side. Production rollout requires verification
of isolation, retention, recovery, and externally visible operation boundaries.
