# InnoVox

**人間とコーディングエージェントの間で、文脈と音声対話をつなぐ基盤。**

会話と作業の進行を読み、プロジェクトが大切にしている目的・保持条件と
照らし合わせて、今伝えると役立つ情報を先回りして提示します。
人間の判断が必要なら音声で相談し、答えを正しい作業へ戻します。

[English](README.md) · [プロダクト方針](docs/product.md) · [設計](docs/architecture.md) · [開発段階](docs/roadmap.md)

## 現在の状態

プロジェクトの基盤を整備している段階です。稼働する公開サービス、
GPT Liveとの実接続、デスクトップのセッション連携はまだありません。
リポジトリの公開と、サービスを誰もが利用できる状態は区別します。

## 目指す体験

- LLMがAskUserを呼ぶ前でも、必要な前提や見落としそうな条件を補える。
- 人間は作業を止めて長文を入力せず、口頭で意図を伝えられる。
- CodexからClaudeへ画面を切り替えても、回答の宛先を取り違えない。
- プロジェクトの目的、保持条件、その理由と訂正の履歴を引き継げる。

まずクラウドで動く体験を優先し、音声はGPT Live、判断はAstraを基本方針とします。
その後、公開された仕様と同じ検証基準で、セルフホストと1台のPCでの利用へ広げます。
APIを使うセルフホストと、推論を含む完全ローカル動作は別の段階として検証します。

## 開発

小さく動く一連の機能を積み上げます。接続部は交換可能にし、バージョン差、
再接続、回答の訂正、誤配送、遅延を初期の受入条件に含めます。
未検証の機能や合成デモを、実接続済みとして扱いません。

詳細は[ロードマップ](docs/roadmap.md)と[開発ルール](AGENTS.md)を参照してください。
